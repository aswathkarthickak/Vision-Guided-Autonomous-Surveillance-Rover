# Vision-Guided Autonomous Surveillance Rover

## Overview

This project presents a Vision-Guided Autonomous Surveillance Rover designed for intelligent security and e-monitoring applications.

The rover uses ESP32 and ESP32-CAM for real-time video streaming and autonomous navigation. Obstacle detection is achieved using an HC-SR04 ultrasonic sensor while motor control is handled by the L298N motor driver.

## Features

- Real-time Video Streaming
- Autonomous Navigation
- Obstacle Detection and Avoidance
- WiFi Based Monitoring
- Low Cost IoT Solution
- ESP32-CAM Integration

## Hardware Components

- ESP32
- ESP32-CAM
- HC-SR04 Ultrasonic Sensor
